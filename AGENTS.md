# Core Principles

* Implementation-first
* Root-cause first
* Correctness first
* Procedural style
* KISS — Keep It Simple, Stupid
* YAGNI — You Aren’t Gonna Need It
* Pragmatic coding
* Refactor over patch
* Single source of truth
* Single path
* Explicit over implicit
* Fewer files, fewer classes, less wrapping, fewer layers
* Minimize cognitive load
* Intent through naming
* Comments explain why
* Preserve behavior, not implementation
* Verify over assume
* Delete over preserve
* Git-based workflow
* Conventional Commits
